Unlimited Ads

Setup Guide

Get running in under 5 minutes. Generate static ads and animated videos for any product, any brand, on demand.

One-time setup

Do these steps once. Takes about 5 minutes.

  1. Download Claude Code

    Go to claude.ai/code and download the app. You need an Anthropic account — free to sign up.

  2. Open the Unlimited Ads folder in Claude Code

    Open Claude Code → click Open Folder → select the Unlimited Ads folder you downloaded. You should see CLAUDE.md, scripts/, and workspace/ in the sidebar.

  3. Get a FAL API key

    Go to fal.ai → sign up → click your avatar → API Keys → create a new key and copy it.

    Open the .env file in the Unlimited Ads folder and replace the placeholder with your key:

    FAL_KEY=your-actual-key-here
    Can't see .env? It starts with a dot, which hides it on Mac. Press Cmd + Shift + . in Finder to show hidden files. In Claude Code it's always visible in the sidebar.
  4. Install Python packages

    Open the terminal in Claude Code and run this command. You only need to do this once.

    pip3 install fal-client requests
    If you see "pip3 not found", try pip install fal-client requests without the 3.

The three skills

Three commands. Run them in this order the first time.

Command What it does When to run
/brand-dna-builder Researches your brand from its URL — colors, photography style, visual rules. Saves a visual brief and creates your folder structure. Once per brand
/ad-generator Analyzes your reference images, researches the product, writes a creative brief for approval, then generates one ad per reference. Every time you want ads
/ad-animator Reads a generated ad, identifies what can naturally move in the scene, writes a motion brief for approval, then animates it via Kling 3.0. After /ad-generator, for video

Creating ads

Follow these steps every time you start with a new brand.

  1. Run /brand-dna-builder

    Type in the Claude Code chat:

    /brand-dna-builder

    Claude will ask for your brand's website URL. Paste it in. It researches the brand's visual identity — colors, photography style, voice — and saves everything to a visual-brief.md. It also creates your product-images/ and references/ folders.

  2. Drop in your product image

    Add your product photo to:

    workspace/brands/[your-brand]/product-images/
    • One clean, front-facing shot is enough
    • Name it clearly with lowercase and hyphens: face-serum.jpg
    • Plain or white background works best
  3. Add reference images

    Drop reference images into:

    workspace/brands/[your-brand]/references/
    • Pinterest screenshots, competitor ads, editorial shots — anything showing the visual direction you want
    • Each reference becomes one ad. 4 references → 4 ads. 10 references → 10 ads.
    • 4–8 well-chosen images is the sweet spot
  4. Run /ad-generator
    /ad-generator
    • Analyzes every reference — lighting, color grade, composition, mood
    • Researches the product and pulls real customer language
    • Writes one creative brief per reference and shows them all at once
    • Waits for your approval — read and adjust before saying go
    • Generates all ads in sequence, one per reference

    Output saved to: workspace/brands/[brand]/ads/[product]_[date]/ref-1/, ref-2/ ...

  5. Run /ad-animator (optional — for video)
    /ad-animator
    • Claude reads the generated image and identifies what can naturally move — steam, liquid, light shifting, a subtle eye blink
    • Writes a motion brief and waits for your approval before generating
    • Outputs a 5-second MP4 saved next to the static ad
    • Camera and text always stay locked — only natural scene elements move

Running more ads

After the first brand is set up, new ads take about 3 minutes.

Same brand, new product

Drop a new product image into product-images/ and run /ad-generator. If there are multiple images Claude will ask which one to use.

Different visual direction

Clear the references/ folder, drop in new reference images, and run /ad-generator. Brand DNA stays the same — only the creative direction changes.

New brand

Run /brand-dna-builder with a new brand URL. Each brand gets its own folder. Manage as many brands as you want.

Adjust and regenerate

If you don't love an output, tell Claude what to change — the headline, the composition, the background color. Claude updates the brief and regenerates. Each static ad costs ~$0.12 so iteration is cheap.

Generation costs

Pay-per-generation via FAL. No subscription. Add credits as needed.

Static ad — GPT Image 2.0 (high quality) ~$0.12
Animated video — Kling 3.0 Pro (5 sec) ~$0.35
Brand DNA build — web research only Free

Troubleshooting

"FAL_KEY not found"

Open .env and confirm your key is there with no spaces: FAL_KEY=your-actual-key. The file must be in the root of the Unlimited Ads folder.

"No brand found" when running /ad-generator

Run /brand-dna-builder first. It creates the visual-brief.md that /ad-generator looks for. Check that the file exists at workspace/brands/[brand]/visual-brief.md.

"No reference images found"

Drop images into workspace/brands/[brand]/references/ before running /ad-generator. References are required — each one becomes one ad.

Generation fails with a server error

FAL occasionally has brief outages. Wait 30 seconds and try again. If it keeps failing, check your FAL dashboard to confirm your key is active and has credit.

Product packaging looks wrong in the output

Make sure your product image is front-facing, well-lit, and the label is clearly readable. A plain or white background gives the model the best reference.

Animation looks too dramatic

Run /ad-animator again and tell Claude to tone it down — "less movement on the steam" or "only animate the light shift." The motion brief is editable before generation.
